# Рассказы из русской истории — статистика лекций

Публичная страница со статистикой лекций Владимира Мединского на YouTube, Rutube и VK Видео.

- `index.html` — страница дашборда (открывается через GitHub Pages).
- `data/` — данные: `videos.json` (ролики на дату последнего замера), `history.json` (еженедельные замеры), `yt_monthly.json` (история YouTube по месяцам из YouTube Studio), `vk_week.json` (неделя 21–27.10.2026 из VK Видео), `meta.json` (дата обновления).
- `assets/` — d3 и небольшой загрузчик данных.

Данные обновляются раз в неделю, по понедельникам.
